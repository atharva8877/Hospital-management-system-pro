This requires additional ESP32 firmware and audio playback changes; the
existing app.py does not send audio to an ESP32-connected speaker. Do not
connect a low-impedance speaker directly to an ESP32 GPIO.

Resistors
---------
The status LED requires the listed 330 ohm current-limiting resistor in series.
Connect GPIO 4 -> resistor -> LED anode (long leg); connect the LED cathode
(short leg/flat side) to ESP32 GND. The resistor can be placed on either side
of the LED as long as it is in series.

No external resistors are required for the four buttons in this design:
firmware configures their GPIO pins as INPUT_PULLUP, so each button connects
its GPIO to GND when pressed. The TFT may need a resistor for a bare backlight
LED, but many TFT breakout boards already include one; check the module.

Typical connections used by this project
----------------------------------------
TFT to ESP32:
  TFT VCC   -> supply required by the specific display module
  TFT GND   -> ESP32 GND
  TFT CS    -> GPIO 13
  TFT D/C   -> GPIO 27
  TFT MOSI  -> GPIO 23
  TFT SCK   -> GPIO 18
  TFT RST   -> optional on a physical module; connect to the module's reset
               input as required, or use the display library's software reset.
  TFT MISO  -> optional if the project does not read data from the display.
  TFT LED   -> backlight supply required by the specific display module

Buttons (use the ESP32's internal pull-ups; the other side of each button goes
to GND):
  Emergency -> GPIO 32
  Water     -> GPIO 33
  Washroom  -> GPIO 25
  Food      -> GPIO 14

Electrical safety
-----------------
- ESP32 GPIO pins use 3.3 V logic and are not 5 V tolerant. Never connect 5 V
  directly to an ESP32 GPIO.
- TFT breakout boards differ: check the exact module's supply and logic-level
  requirements before wiring. Use a suitable level shifter if the display's
  SPI inputs require 5 V logic.
- Do not assume the ESP32 VIN/5V pin is a regulated 5 V output when the board
  is powered in a different way. Follow the board and display manufacturers'
  wiring/power specifications.
- The buttons in this project are separate push buttons. The colored button
  shapes drawn on the TFT are visual only; the display is not a touchscreen.
